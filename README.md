*Linux Command-Line Practice*

Project Overview
This repository documents my hands-on practice with Linux commands and basic system administration.

Objective
To develop practical Linux skills relevant to IT Support, troubleshooting, and cybersecurity.

Environment
- Operating System: Kali Linux
- Terminal: Linux command line

Topics Practised
- File and directory management
- File permissions and ownership
- User and group permissions
- Process management
- Networking commands
- Searching and filtering text
- File compression and archiving

Commands Practised

| Category | Commands |
|---|---|
| File management | ls, pwd, cd, mkdir, cp, mv, rm |
| File permissions | chmod, chown |
| Processes | ps, top, kill |
| Networking | ip, ping, ss |
| Text processing | grep, cat, find |
| Archives | tar, gzip |

Key Learning Outcomes
- Navigating the Linux file system
- Understanding file permissions
- Inspecting processes and network information
- Searching for files and text
- Creating compressed archives

Disclaimer
This repository contains learning exercises performed in a personal lab environment.
